# место — предметы для жизни

Демонстрационный магазин интерьерных вещей в белой палитре: полки, искусственные цветы, керамика и текстиль.

[Открыть сайт на GitHub Pages](https://sema88.github.io/mesto-home/)

[Версия в Sites](https://mesto-white-interior-kt.decentpig128.chatgpt.site)

## Что работает

- Каталог из восьми предметов, фильтры категорий, поиск и сортировка.
- Карточки товаров, избранное и корзина с подсчётом суммы.
- Сохранение корзины и избранного в браузере.
- Адаптивная вёрстка и поддержка уменьшенного движения.
- Крупный текст и плавное появление блоков снизу при прокрутке.

Заказы, доставка и оплата демонстрационные. Сервер и платёжные интеграции не подключены.

## Запуск

Нужен Node.js 18 или новее. Устанавливать зависимости не требуется.

```sh
npm start
```

Откройте http://127.0.0.1:4173.

## Структура

- `index.html` — разметка страницы и диалогов.
- `style.css` — стили, мобильная версия, типографика Lora / Nunito Sans.
- `app.js` — каталог и взаимодействия.
- `assets/` — изображения сайта.
- `scripts/serve.mjs` — локальный HTTP-сервер.

Для размещения на статическом хостинге достаточно загрузить `index.html`, `style.css`, `app.js` и `assets/`. Сборка не требуется; пути к ресурсам относительные.

GitHub Pages публикует корень ветки `main`. После новых коммитов сайт обновляется автоматически. Файл `.nojekyll` отключает обработку Jekyll.

## Изображения

Интерьерное фото `assets/hero.png` создано с помощью Imagegen. Фотографии товаров используются как иллюстрации демоконцепта. Источники и ссылки доступны в окне «О демоверсии и фотографиях» на сайте: BAUMHIRSCH, Modern Locke, Wurm, Adairs, Cut My, Quirk Space, Mango, Felt+Fat.

## Проверка

```sh
npm run check
```

Проверены загрузка изображений, фильтрация каталога, добавление в корзину и сумма, сохранение корзины после перезагрузки и мобильная вёрстка при ширине 390 px.
